IMPORTANT CUSTOMISE BEFORE SUBMISSION:
- Replace the placeholder phone number in contact.html with your number.
- Replace Instagram and Facebook homepage links with your actual profile/page URLs.
- Product names, prices, images and contact details are sample content for a student demo.
- Product images are loaded from Unsplash and require an internet connection.
- Add to Cart and Buy Now open a marketplace-style checkout panel for delivery name, mobile, PIN code, full address, city, state, and address type. Place Demo Order shows a sample confirmation only; no real payment/order is processed.
- Google Analytics is not configured in this starter site.

PUBLISH ON GITHUB PAGES USING A PHONE:
1. Sign in or create a GitHub account at https://github.com
2. Tap +, choose New repository.
3. Repository name: threadora-store
4. Choose Public, then Create repository.
5. Open Add file > Upload files.
6. Upload all 8 files from this folder (the six HTML files, style.css, script.js; README is optional).
   If uploading a ZIP, extract it first. Upload the files themselves, not a folder containing another folder.
7. Tap Commit changes.
8. Open repository Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select Branch: main and folder: /(root), then Save.
11. Wait a few minutes and refresh Settings > Pages. Open the published URL shown there.
12. Check all six pages and take screenshots for your assignment.

If you need to edit details later, open the relevant file in GitHub and use the pencil/edit icon, then commit changes.
